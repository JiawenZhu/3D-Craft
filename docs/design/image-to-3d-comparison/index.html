04 / Product implications

What belongs in 3D Craft?

The existing flow is concept image → selected source → confirmation → generation → GLB review. A provider change must preserve that source handoff, user billing, and model export.

For the first provider pilot

Keep Rodin as the current default. Tripo saves $0.18 per listed run and Seed3D saves $0.047, making them the only cheaper Atlas candidates from this test. Both need mesh and texture optimization before iPhone use, so net savings are not yet proven. Hunyuan Rapid is light but costs more and resembles the source less. Exclude HI3D Quality and Master on cost.

  • Keep the original selected image and generation metadata with the finished asset.
  • Store provider prediction IDs, poll to a terminal status, and settle Tokens only after a usable mesh is verified.
  • Check GLB orientation, texture maps, vertex count, and download size on a physical iPhone.

Limits of this round

  • One dragon is not enough to rank all subjects. A character with thin accessories and a hard-surface prop should be the next two inputs.
  • HI3D accepts up to four views and Meshy offers a multi-image endpoint, but this page does not claim a multi-view fidelity result from a single source.
  • The same Atlas catalog also lists four text-to-3D endpoints. They require a prompt rather than this image and are excluded from the same-input quality ranking.
  • Geometry density does not indicate rigging, animation, printability, or game performance. Those require separate checks.
