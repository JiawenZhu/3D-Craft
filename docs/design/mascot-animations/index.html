Mascot waiting animations

Six looping clips: two mascots × three waiting phases. Soft lavender uses the original blue Cloud Dragon and emerald green uses the original Panda Chef. Each clip was generated from the app's own original concept art with fal Seedance 2.5 (bytedance/seedance-2.5/image-to-video, 480p, 4 s, no audio). The original art was given as both the start and the end frame. The last 0.25 s of each clip is blended back into its first frame, so the loop point is hidden. This page plays the same files the iOS app bundles (ios/CraftStudio/Resources/Mascot/) with the same circular framing and sizes (in points = CSS px).

These are activity indicators only. The mockups show no percentages because the app shows only the progress the service reports, next to the card. Clips pause and show the still original art when Reduce Motion or Increase Contrast is on, when the app is backgrounded or in Low Power Mode, and when the job is no longer active.

Playback also pauses while this tab is hidden, like the app's background gate.
