Quality by resolution

  • 480p · tested: four Atlas models and the earlier fal Seedance 2.5 baseline. Seedance 2.5 had the best balance of source fidelity and loop continuity in this single shot; Mini moved more but shifted lighting.
  • 720p · price and API verified: native output is available on all but H3; no matched clip was rendered. Sharper output cannot be assumed to preserve character details or timing better.
  • 768p · tested on H3: smooth head and gaze movement, but its extra pixels mean the apparent sharpness is not a fair 480p A/B result.
  • 1080p · price and API verified: available natively on Seedance 2.0, 2.5, and Wan Prime; Mini offers SR only. No matched clip was rendered.

Beyond 1080p

  • 2K: H3 lists this tier on both providers. Atlas’s price matches fal’s $0.13/s; visual quality remains untested here.
  • 1440p: Atlas Mini, Seedance 2.0, 2.5, and Wan list SR/ESR outputs. They are enhanced images, not direct evidence of extra generated detail.
  • 4K: Atlas Seedance 2.0 and fal Seedance 2.0 list native 4K. Atlas Seedance 2.5 and Wan list 4K ESR; fal H3 lists 4K. None was rendered in this study. The 960×960 source cannot verify true 4K scene detail, so a future test should inspect texture, silhouette stability, temporal flicker, and the 4K invoice before marketing it as higher quality.
04 / Product decision

Where 3D Craft saves

Use a controlled pilot before changing the deployed animation pipeline. The Gemini image service has existing credits and serves a different job than the waiting clips.

Animation routing

  • Pilot Atlas Seedance 2.5 for a 4-second 480p square mascot loop. The listed $0.1397/s versus fal’s roughly $0.2205/s is about 37% less, or roughly $0.32 less for a 4-second reference clip.
  • Keep fal MiniMax H3 when H3 is specifically wanted: fal’s 768p rate is 25% below Atlas’s.
  • Do not auto-select Mini or Wan yet. The Mini test has a visible seam; Wan’s movement is too subtle for a prominent loading animation. Test with both blue dragon and green panda, all three phases, before production.

Image and 3D opportunities

  • Keep Gemini 3 Pro Image while existing credits last. Google lists $0.134 for a 1K/2K image; Atlas Seedream 5.0 Pro lists $0.072 at 2K. That is a potential 46% lower list price, but prompt fidelity and reference preservation need separate A/B tests.
  • Try Tripo H3.1 on non-critical 3D jobs. Atlas’s live pricing panel shows $0.22 with standard texture and $0.11 without; current fal Rodin is $0.40. This is a model change, so cost alone is not enough.
  • Atlas Seed3D 2.0 is $0.353/model and Hunyuan Rapid with PBR is $0.50. Neither plainly beats the current $0.40 Rodin route. Existing multi-view Hunyuan pricing can already be lower for suitable work.
Implementation note: Keep provider credentials on the server and continue showing only real job status. If the production switch is approved, route requests by model, persist Atlas prediction IDs, settle Tokens only on success, and use the app’s current MP4 transcode and Reduce Motion still image. The existing server/pricing.py Seedance catalog sentence says a square 4 s clip is about $0.46, while its current token formula and 640×640 dimensions imply about $0.82 before headroom; verify and correct that display copy before relying on it for a user-facing quote.
