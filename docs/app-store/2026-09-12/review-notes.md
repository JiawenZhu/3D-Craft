# Review and TestFlight material — draft

## Beta description
3D Craft turns text and reference images into concept art and 3D assets. Explore curated animal and object examples, inspect models with lighting and zoom controls, and export GLB files with an editable browser-game brief.

## What to test
1. Open a fresh installation over cellular and a separate Wi-Fi network with no Mac companion.
2. Create concepts from text; refine in conversation. Import a camera/photo reference and confirm the intended source is used.
3. Select a concept, generate a model, background/reopen the app, and confirm the result remains in the library without duplicate charges.
4. Rotate, zoom, change lighting, inspect original concepts, and export the original GLB.
5. Share model + GAME_BRIEF.md using the native share sheet. Open Builder is an external handoff, not automatic game creation.
6. Repeat key flows on iPhone and 13-inch iPad, in both emerald and lavender themes.
7. In Apple Sandbox, test purchase, renewal, restore/recovery and cancellation with the server ledger. No real card details belong in review notes.

## App Review notes to finalize
- Category: Graphics & Design. This is an asset creation app, not a downloadable-game marketplace.
- Curated gallery examples are supplied by 3D Craft. Personal creations are separate; no public user feed is currently advertised.
- ChatGPT connection is optional for provider features; it is not a replacement for app account identity. Gemini path must be usable by the reviewer independently.
- External game handoff transfers the actual GLB and text brief through user-selected iOS sharing. It does not execute downloaded game code in the app.
