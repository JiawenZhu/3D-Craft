# Submission checklist

## Build and service

- [ ] Production HTTPS backend, durable identity, private files and recovery are verified without the Mac.
- [ ] StoreKit products, localized pricing, transaction verification and subscription lifecycle pass Sandbox/TestFlight.
- [ ] Privacy consent, policy, support and applicable deletion are implemented and reachable.
- [ ] Final app and SDK privacy manifests, age/content controls and encryption declarations reviewed.
- [ ] iPhone and iPad release candidate tested, including accessibility and offline/error states.
- [ ] Confirm App ID registration; create app record; set version/build and archive for App Store distribution.
- [ ] Upload build and wait for Apple processing; fix validation errors before selection.

## Listing and business

- [x] Apple account financial setup inspected: agreements, bank and tax active.
- [x] Draft English and Simplified Chinese listing text prepared and length checked.
- [x] Seven native screenshots captured for both target families.
- [x] Three approved-art promotional directions prepared for review.
- [ ] Replace generated phone inserts with exact release captures; final screenshot typography/layout review.
- [ ] Confirm support email, website routes, product terms and commercial prices.
- [ ] Configure in-app purchase records/subscription group with approved values and review screenshots.
- [ ] Complete final metadata, privacy labels, age rating, content rights, regions and regulatory fields.
- [ ] Reviewer contact, accessible backend, demo access and purchase instructions supplied.
- [ ] Select processed build; resolve all missing metadata; review the complete submission.
- [ ] Submit only after the release gates pass; choose the intended release timing.
