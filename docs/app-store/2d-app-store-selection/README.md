# 3D Craft — 2D App Store image selection

This selection supersedes the earlier mixed 2D/3D screenshot selection.

Use the original 2D concept pictures shown in the app gallery. No reconstructed 3D model renders, lighting screens, or AI-redrawn promotional inserts are included.

- `original-2d-art/`: seven unchanged original PNGs: Lantern Cat, blue dragon, Moon Fox, Moss Robot, Panda Chef, Bunny Knight and tropical island.
- `screenshots/iphone-6.9/`: four unchanged native screenshots, 1320 × 2868.
- `screenshots/ipad-13/`: four unchanged native screenshots, 2064 × 2752.
- `branding/`: existing approved app icon.

Use native screenshots for the App Store device screenshot slots. Original square artworks are source assets for layout and should not be presented as interactive model renders. Their dimensional illustration style is retained; “2D” here means the original static concept PNGs, not a new flat illustration style.

Files are byte-for-byte copies; `manifest.json` records source paths, dimensions and hashes. Older files remain in the dated preparation folder for reference and are not included in this selection. Production release gaps from that preparation remain unresolved.
